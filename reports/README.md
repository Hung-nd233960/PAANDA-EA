# Reports

Guide to this directory. **[`REPORT.md`](REPORT.md) is the authoritative document** —
where anything here disagrees with it, it is correct.

## Deliverables

| File | What it is |
|---|---|
| [`REPORT.md`](REPORT.md) | **The report.** Full methodology, theoretical background, derivations, results, statistical tests, discussion and limitations. IEEE-style, 15 tables, 8 figures. |
| [`REPORT_SHORT.md`](REPORT_SHORT.md) | Condensed version of the same content, plus a point-by-point reviewer-response section. |
| [`figures/`](figures/) | Figures for both documents, each as `.png` (embedded in the report) and `.svg`. Generated by `scripts/report_figures.py`, `scripts/confusion_matrices.py` and the `scripts/manuscript_*.py` set. |
| `figures/committed_panel_markers.csv` / `.xlsx` | Supplementary per-locus marker table: 94 unique SNPs across the three committed panels, with coordinates, rsIDs, alleles, per-population frequencies, maximum pairwise Hudson *F*<sub>ST</sub>, and fold-selection frequency. |

## Building the report

Figures are embedded as PNG and citations are Pandoc `[@citekey]` markers resolved by
citeproc, so the reference list is generated at build time — never hand-edited.

```bash
cd reports
pandoc REPORT.md --citeproc --csl=ieee.csl --bibliography=references.bib -o REPORT.docx
```

Verified with Pandoc 3.7.0.2: 14 references resolve, tables render as real Word
tables, and all 8 figures embed. Substitute `-o REPORT.pdf` for PDF (needs a LaTeX
engine). `references.bib` holds the bibliography; author initials for the three
published-panel entries are abbreviated to "et al." and can be expanded from the DOIs
if a full author list is needed.

## Historical documents

These are retained as a development record. All three carry inline notices at the
claims that changed; **none should be cited in preference to `REPORT.md`.**

| File | Why it is superseded |
|---|---|
| [`METHODOLOGY.md`](METHODOLOGY.md) | Working methodology write-up. Predates the combined-block fix, and its panel-size-dependent pool recommendation was reversed. |

| [`NESTED_CV_MASTER_REPORT.md`](NESTED_CV_MASTER_REPORT.md) | Internal synthesis written mid-rework. Pre-fix numbers; also frames results as a before/after comparison against the leaky baseline, which the final report deliberately does not do. |

## Known gaps

- **No slide deck.** `DOCS_PLAN.md` §2.2 plans one; it was never built against the
  final report. Earlier `SLIDES.md`/`SLIDES.pptx` drafts were abandoned as stale.
- **Single cohort.** Every number in the report comes from one 504-individual 1000
  Genomes EAS cohort. No independent validation cohort was evaluated — the main
  limitation on publishability (`REPORT.md` §VI-E).
- **One stale archived result file**, flagged in
  [`../results_archive/nested_leakfree_v1/MANIFEST.md`](../results_archive/nested_leakfree_v1/MANIFEST.md).
